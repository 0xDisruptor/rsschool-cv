Vowel Count

JavaScript

Count the vowels in a lowercase string. The vowels are a, e, i, o and u.

View the problem on Codewars

vowel-count.js Sample solution
function getCount(str) {
  let count = 0;
  const vowels = 'aeiou';

  for (const char of str) {
    if (vowels.includes(char)) {
      count += 1;
    }
  }

  return count;
}

Example: getCount('abracadabra') returns 5.
