## 4. Code Examples

**Task:** [Vovel Count](https://www.codewars.com/kata/54ff3102c1bad923760001f3).

Count the vowels in a lowercase string. The vowels are a, e, i, o and u.

```javascript
function getCount(str) {
  let count = 0;
  const vowels = 'aeiou';

  for (const char of str) {
    if (vowels.includes(char)) {
      count += 1;
    }
  }

  return count;
}
```
